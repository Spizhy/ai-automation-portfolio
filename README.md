# 🚀 Портфолио: Боженко Илья (AI-DevOps & AI-Инженер)

Интерактивное веб-портфолио и витрина инженерных систем автоматизации процессов, разработанных **Боженко Ильёй** (Инженер по ИИ-автоматизации и DevOps).

Дизайн и интерфейс вдохновлены эстетикой современной среды разработки (IDE window framework, перетаскиваемые информационные панели, статус-бар, динамическая смена тем и интерактивные терминальные кейсы).

---

## 🌐 Быстрый запуск на Vercel
Сайт представляет собой статический высокопроизводительный SPA (HTML5 / Tailwind CSS / Vanilla JS):
1. Импортируйте данный репозиторий в **[Vercel](https://vercel.com/new)**.
2. В настройках проекта оставьте стандартные параметры (`Framework Preset: Other`, `Root Directory: ./`).
3. Нажмите **Deploy** — проект мгновенно разворачивается с поддержкой HTTPS и CDN.
