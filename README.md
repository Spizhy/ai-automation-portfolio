# 🚀 Проект: Портфолио (Веб-сайт)

Современный, производительный и доступный веб-сайт с полным набором семантических HTML5-тегов, микроразметкой Schema.org, мета-тегами Open Graph/Twitter Cards и ARIA-атрибутами.

---

## 📁 Структура проекта

```text
├── index.html          # Главная страница (разметка со всеми атрибутами)
├── css/
│   └── style.css       # Стили, переменные тем (Dark / Light), адаптивность
├── js/
│   └── main.js         # Интерактивность (переключатель темы, фильтры, модалки, тосты)
├── assets/
│   ├── images/         # Изображения и превью
│   └── resume.pdf      # Резюме / документы (заглушка)
└── README.md           # Документация и инструкции
```

---

## 🌟 Реализованные возможности и атрибуты

1. **SEO & Мета-атрибуты:**
   - `<meta charset="UTF-8">`, `viewport`, `robots`, `author`, `keywords`, `description`
   - **Open Graph & Twitter Cards** для красивого шеринга в Telegram, VK, соцсетях
   - **Schema.org JSON-LD** (структурированные данные типа `Person`)
   - `theme-color` с поддержкой `prefers-color-scheme`

2. **Доступность (A11y):**
   - Skip-link (`.skip-link`) для перехода сразу к основному содержимому
   - Семантические теги: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<blockquote>`, `<dialog>`, `<footer>`
   - ARIA роли и атрибуты (`aria-label`, `aria-labelledby`, `aria-hidden`, `aria-expanded`, `aria-controls`, `aria-live`)

3. **Интерактивные функции:**
   - 🌓 **Переключение темы (Dark / Light)** с сохранением выбора в `localStorage`
   - 📱 **Адаптивное мобильное меню** (бургер)
   - 🔍 **Фильтрация проектов** по категориям без перезагрузки
   - 💬 **Всплывающее модальное окно** на базе нативного `<dialog>`
   - 📊 **Анимация счетчиков** при скролле (IntersectionObserver)
   - 📝 **Форма обратной связи** со всеми типами инпутов (`text`, `email`, `tel`, `select`, `textarea`, `file`, `checkbox`) и валидацией
   - 🔔 **Всплывающие Toast-уведомления**
   - ⬆️ **Кнопка "Наверх"** с плавным скроллом

---

## 💻 Как открыть и тестировать

- **Простой способ:** Открыть `index.html` двойным кликом в любом браузере (Chrome, Edge, Firefox).
- **Через локальный сервер (по желанию):**
  - Python: `python -m http.server 8000`
  - Node.js: `npx serve` или расширение Live Server в VS Code.
