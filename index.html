about-me

Привет! Меня зовут Боженко Илья, я Инженер по ИИ-автоматизации и DevOps.

Моя цель — позиция стажёра ИИ-DevOps / AI-инженера для решения задач автоматизации разработки, контейнеризации сервисов, настройки CI/CD-пайплайнов и интеграции AI-моделей в инфраструктуру проектов.

Создаю продакшн-инструменты в Open Source, проектирую Telegram и Slack-ботов, настраиваю Docker, Kubernetes и автоматическую сборку образов в GitHub Actions / GitLab CI.

Привет! Я Боженко Илья — Инженер по ИИ-автоматизации и DevOps (Москва / удалённо, с октября 2025 г. по настоящее время).

Настроил Docker-контейнеры и базовые пайплайны GitHub Actions / GitLab CI для автоматической проверки кода и сборки образов в репозиториях.
